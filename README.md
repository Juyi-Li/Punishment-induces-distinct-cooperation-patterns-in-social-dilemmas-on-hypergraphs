# Punishment-induces-distinct-cooperation-patterns-in-social-dilemmas-on-hypergraphs

## DESCRIPTION
This repository provides MATLAB code for reproducing the results in the paper:

**Punishment-induces-distinct-cooperation-patterns-in-social-dilemmas-on-hypergraphs**  

## FILES
- `fig2_single_stage.m`  
  Script for reproducing results/plots related to the single-stage cooperation pattern in Figure 2.

- `fig2_two_stage.m`  
  Script for reproducing results/plots related to the two-stage cooperation pattern in Figure 2.

- `fig3.m`  
  Script for reproducing results/plots related to Figure 3.

- `fig4_three_convergence_domain.m`  
  Script for reproducing results/plots related to the three convergence domains in Figure 4.

- `fig4a.m`  
  Script for reproducing panel (a) of Figure 4.

- `fig4b.m`  
  Script for reproducing panel (b) of Figure 4.

- `fig5_benefit_beta.m`  
  Script for reproducing results/plots related to the benefit analysis as a function of `beta` in Figure 5.

- `fig5_betefit_delta.m`  
  Script for reproducing results/plots related to the benefit analysis as a function of `delta` in Figure 5.

- `fig6_2strategy_MC.m`  
  Script for reproducing the Monte Carlo simulation results for the two-strategy setting in Figure 6.

- `fig6_3strategy_MC.m`  
  Script for reproducing the Monte Carlo simulation results for the three-strategy setting in Figure 6.

## INSTALLATION
1. Install MATLAB (R2014a or later recommended).
